⬇ Curio Blinkit Sync

Drag this button to the bookmarks bar. If it won't drag, use Method 1 above.

Use it

  1. Log into seller.blinkit.com.
  2. Open the Inventory tab (click "Stock on hand" to force a real API call so headers are populated).
  3. Click your Curio Blinkit Sync bookmark.
  4. A toast appears top-right. Walks through: Capturing session… → Pulling inventory… → Pulling coverage 60/465… → ✓ Synced 12 SKUs + 45 cities.
  5. Open the Curio dashboard → Blinkit page. New numbers appear.
Weekly cadence: Run this once a week while you're on seller.blinkit.com. The Curio dashboard shows the "last synced" timestamp so you always know how fresh the data is.

If it still doesn't work

  • "⚠ Open seller.blinkit.com first" — you're not on the Blinkit tab. Switch tabs, try again.
  • "⚠ Could not capture session" — the Blinkit app hasn't made an API call yet. Click any tab in the Blinkit UI (Inventory, Catalog, etc.), then click the bookmark again.
  • Nothing happens at all — the bookmark URL may have been truncated. Re-copy using Method 1 above and overwrite the existing bookmark's URL.
  • Chrome strips javascript: on drag — this is a known Chrome security behavior. Use Method 1.
