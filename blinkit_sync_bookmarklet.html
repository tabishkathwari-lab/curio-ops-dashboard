Curio Ops · Blinkit auto-sync

Pull live Blinkit data in one click

Blinkit's seller portal uses a session token that only works while you're logged in. This bookmarklet grabs the current session, pulls inventory + coverage, and pushes to the Curio backend. Dashboard refreshes next time you open it.

Install (one time)

  1. Right-click the button below → Add to bookmarks bar (or drag it to the bookmarks bar).
  2. If it won't drag, right-click the bookmarks bar → Add page…, name it "Curio Blinkit Sync", paste the full javascript:... code from the box below the button into the URL field.
⬇ Curio Blinkit Sync
Raw bookmarklet code (if drag doesn't work)

Use it

  1. Log into seller.blinkit.com.
  2. Navigate to any inventory page (so the session token is active).
  3. Click the Curio Blinkit Sync bookmark.
  4. A toast appears top-right: "Capturing… pulling inventory… pulling coverage… pushing to backend… ✓ Done."
  5. Open the Curio dashboard and refresh — new numbers appear.

What it pulls

  • Inventory — all SKUs with stock on hand (darkstore / warehouse / in-between), unsellables (lost / near-expiry / damaged / expired), incoming scheduled, 7/15/30-day sales, expansion level, pricing.
  • Coverage — every city Blinkit serves, with product stats and darkstore count per city.
  • Also records a last_sync timestamp.
